# Судьба правителей

Учебная игра проекта «История и котики» по скрипту «Иван Грозный» (тема 6, 1533–1598).

- 5 глав-правлений: Елена Глинская → боярское правление → Иван IV и Избранная рада → Ливонская война и опричнина → конец Ивана IV и Фёдор Иоаннович.
- В каждой главе 6 решений: исторический выбор из трёх вариантов, шкалы «Казна / Войско / Знать / Народ» и летописная карта судьбы правителя в конце главы.
- Финал «Летопись века»: хронология, плюсы и минусы царствования Ивана Грозного, словарь понятий.
- 5 жизней на весь путь, прогресс сохраняется в браузере. Один файл `index.html`, без сборки.

## Публикация на GitHub Pages
1. Создайте репозиторий (например, `sudba`) в аккаунте `historyandcats`.
2. Загрузите `index.html` и `README.md` в корень.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Адрес: `https://historyandcats.github.io/sudba/`.
