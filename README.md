# Судьба правителей

Учебная игра-«свайп» проекта «История и котики» по скрипту «Иван Грозный» (тема 6, 1533–1598).

- Ты — кот-советник при московском дворе. Персонажи (бояре, митрополиты, воеводы, купцы) приходят с прошениями — свайпни карточку влево или вправо так, как было на самом деле.
- Шкалы «Казна / Войско / Церковь / Народ» показывают последствия решений, лента времени — путь от 1533 до 1598 г.
- 5 правлений, 32 решения; после каждой главы — судьба правителя, в финале — летопись века и звание.
- 5 свечей: ошибка гасит свечу, без свечей — «опала» и повтор главы. Прогресс сохраняется в браузере.
- Управление: свайп, кнопки или стрелки ← → на клавиатуре. Один файл `index.html`.

## Публикация на GitHub Pages
1. Создайте репозиторий (например, `sudba`) в аккаунте `historyandcats`.
2. Загрузите `index.html` и `README.md` в корень.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Адрес: `https://historyandcats.github.io/sudba/`.
